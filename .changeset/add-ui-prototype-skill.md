Add `ui-prototype`, a skill that prototypes the front end of a user flow in two gated stages: a grayscale mid-fi with defined blocks, hierarchy, surface tones, real key copy, annotations, and side-by-side variants for open decisions, then, only after the user approves it, a hi-fi built on the project's design system, with accessibility and handoff documentation. It offers the prototyping apps the agent can reach (Figma, Paper, Pencil, OpenPencil, Penpot, and similar) and always a self-contained HTML file, which becomes the handoff document.
